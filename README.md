# E.Y.L FM — соцсеть вопросов и ответов в духе ASK.fm 2013

Полноценная соцсеть: регистрация и вход, профили с фото, вопросы (в том числе анонимные),
ответы, лайки, подписки, подарки, уведомления, поиск, настройки. Всё на русском.
Стиль — старый ASK.fm 2013: синяя шапка, белый фон, компактная вёрстка.

## Запуск локально
```
python3 -m venv venv
venv/bin/pip install -r requirements.txt
venv/bin/python app.py
```
Сайт: http://127.0.0.1:5000 — первый зарегистрированный пользователь становится администратором.

## Деплой на AlwaysData (бесплатно)
1. В панели AlwaysData создать сайт (Python) и загрузить файлы проекта (app.py, templates/, static/, requirements.txt).
2. Установить зависимости: `pip install -r requirements.txt` (в окружении сайта).
3. Точка входа WSGI: `app.py`, объект `app`. База SQLite `eylfm.db` создаётся сама.
4. Задать переменную окружения `EYLFM_SECRET` — длинная случайная строка.
5. Перезапустить сайт. Данные хранятся в `eylfm.db` и `static/avatars/` — они сохраняются между перезапусками.

## Что внутри
- `app.py` — весь бэкенд (Flask + SQLite)
- `templates/` — страницы (Jinja2)
- `static/style.css` — стиль старого ASK.fm
- `static/avatars/` — загруженные фото профилей

## Честные ограничения
- Нет CSRF-токенов для API — есть простая защита форм токеном сессии.
- Нет модерации и жалоб — удаление вопросов/ответов только автором и получателем.
- Аватары хранятся файлами на диске (до 2 МБ, PNG/JPG/GIF).
- Почта и восстановление пароля не подключены — пароль меняется в Настройках.
